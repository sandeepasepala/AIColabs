# 🎥 VideoGen Notebooks

Collection of Google Colab notebooks for open-source AI video generation models:

- **[MiniMax (FreeVideo)](./minimax/)**: MiniMax H3 inference engine with low-memory adaptive execution and dedicated Web UI via Cloudflare tunnel.
- **[LTX-Video](./LTX_2/)**: Lightricks LTX-Video generator notebook.
- **[Wan2GP](./Wan2GP/)**: Wan2GP video generation on Colab with Gradio interface.
- **[Wan2.1 / SVinfy](./Wan2_1/)**: Stable Video Infinity & Wan2.1 ComfyUI setup.
